How to use

MCP server Fastest, nothing to install

A public remote MCP server (Streamable HTTP, no login). Tools: get_cv, get_projects and check_fit; resources: both CVs, projects and resume.json. Listed in the official MCP Registry as io.github.psagarna/cv.

https://mcp.psagarna.workers.dev/mcp

Call the server from your browser and see exactly what an AI agent gets back.

Pick a tool and press Run.

check_fit returns my CV, projects and the format for the assessment. Your agent's model writes the verdict.

  1. In claude.ai or Claude Desktop, open Settings → Connectors.
  2. Click Add custom connector. Name it Pablo Sagarna CV and paste the URL above.
  3. In a new chat, enable the connector from the tools menu.
  4. Ask “Does Pablo Sagarna fit this role?” and paste the job description.
  1. Add the server from your terminal:
claude mcp add --transport http pablo-sagarna https://mcp.psagarna.workers.dev/mcp
  1. Run /mcp inside Claude Code to check it is connected.
  2. Ask about me, or paste a job description and ask whether I fit.

Cursor, Windsurf and most MCP clients accept a remote server in their MCP config file (for Cursor, ~/.cursor/mcp.json):

{
  "mcpServers": {
    "pablo-sagarna": {
      "url": "https://mcp.psagarna.workers.dev/mcp"
    }
  }
}

VS Code uses .vscode/mcp.json with "servers" and "type": "http". Check your client's docs for the exact key names.

The server speaks JSON-RPC over HTTP, so you can try it without an agent. List the tools:

curl -s https://mcp.psagarna.workers.dev/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

Get my CV in Spanish:

curl -s https://mcp.psagarna.workers.dev/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"get_cv","arguments":{"lang":"es"}}}'

Check fit for a role. It returns my CV, projects and the format the assessment should follow, ready to pass to your LLM:

curl -s https://mcp.psagarna.workers.dev/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"check_fit","arguments":{"job_description":"Head of AI Architecture: 10+ years in enterprise architecture, LLMs and cloud","lang":"en"}}}'

Find it in the official MCP Registry:

curl "https://registry.modelcontextprotocol.io/v0/servers?search=io.github.psagarna/cv"
