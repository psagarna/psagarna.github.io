AgendaWEB - 2010

Sistema de gestión empresarial (ERP) diseñado para digitalizar y optimizar los procesos administrativos de organismos públicos locales y regionales.

Permite a cualquier usuario suscripto seguir en línea la evolución de sus trámites iniciados con el organismo, desde el alta hasta su finalización.

Además, facilita el seguimiento, gestión y almacenamiento documental relacionados con habilitaciones, pagos y cobros de tributos o tasas que exigen los diferentes organismos publicos locales y/o regionales tanto para personas físicas como jurídicas.

Technology Stack: Java, PHP, log4j, Mysql, HTML, Javascript, CSS running on Tomcat and Apache Server
